## How to run 🏃
Clone repository:
```bash
git clone https://github.com/ViLP357/speedMathTraining.git
```
Install depencies:
```
npm install 
```

In main folder speedMathTraining go to...
``` 
/frontend/speedMathTrainingFrontend

```

and

```
npm run dev
```

or

``` 
npm run build
npm run preview
```
